Drop a file. Get Markdown.

A free, open-source desktop app for Microsoft's markitdown. Drop a file anywhere in the window or paste a link, and the .md saves itself to your Downloads folder. No export step, no command line.

Download for Windows (.exe) macOS and Linux

Unofficial, open-source, not affiliated with Microsoft.

How it works

  1. Add something

    Drop files or folders anywhere in the window, use Add files, or paste a webpage or YouTube link.

  2. It converts right away

    In the background, so the window stays usable. One failed file does not stop the rest.

  3. It is already in Downloads

    Then copy the Markdown, open the file, or show it in its folder.

Why this exists

markitdown is a Python library and a command-line tool: you run it, redirect the output, and manage the files. This puts a window around the same engine.

The moment a file converts, its Markdown is in your Downloads folder under the original name. An existing file is never overwritten.

~/Downloads/report.md, report (1).md

A list that answers first

One line says what is ready and what needs you. Each status has its own mark, so it reads without color.

Failures that say why

"Unsupported format", "disk full", "no text found", with a Retry button on the row and the library's own words in the detail pane.

Preview and edit

Read the rendered result or edit the raw Markdown, then copy it or save a copy elsewhere. A very long result previews only its beginning; the Markdown and the saved file stay complete.

Light and dark

Follows your system, or choose in the View menu.

English and Spanish

Switch live from the menu bar, with no restart.

Advanced options, out of the way

Plugins, Azure Document Intelligence, and format hints live in their own settings dialog.

Supported formats

Anything markitdown supports, including:

  • PDF
  • Word
  • Excel
  • PowerPoint
  • Images (EXIF, OCR with Azure)
  • Audio (transcription)
  • HTML
  • CSV
  • JSON
  • XML
  • ZIP archives
  • EPub
  • YouTube links
  • Web pages
